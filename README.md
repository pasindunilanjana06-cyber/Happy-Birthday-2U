# Happy Birthday 🎂

A cute pink-themed static birthday page for a special girl.

## Customize

- **Name**: change the text inside `<span id="name">Name here</span>` in `index.html`.
- **Panda GIF**: replace the `src` of `#panda-gif` in `index.html` with your own GIF link.

## Host on GitHub Pages

1. Create a new repo on GitHub and push these files to it.
2. In the repo go to **Settings → Pages**.
3. Under **Branch**, select `main` (and keep `/ (root)`), then click **Save**.
4. Your site will be live at `https://<username>.github.io/<repo>/`.

No build step needed — it's plain HTML/CSS/JS.
